# Wall Climber

Präziser 2D-Parkour-Plattformer fürs Handy. **Spielen:** https://additiv3.github.io/wallclimber/

Auf dem iPhone in Safari öffnen, dann *Teilen* → *Zum Home-Bildschirm*. Das Spiel läuft komplett
im Browser, funktioniert auch offline und speichert den Spielstand nur auf dem eigenen Gerät.

Dieses Repository enthält nur das fertig gebaute Spiel. Es wird automatisch veröffentlicht.
